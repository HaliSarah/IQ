The rewrite pass tries a small backend proxy first (at /api/rewrite), which calls Claude to actually rework phrasing and sentence structure — not just dictionary word swaps. Your API key stays on the server; this page never sees it. If the proxy isn't reachable — no internet, the backend isn't deployed yet, or you've opened this file outside its hosted site — it automatically falls back to a local rule-based engine that specifically targets things like tidy "X leads to Y, so Z" cause-effect chains and self-summarizing closers ("...and that's a cycle that keeps reinforcing itself"), on top of phrase swaps and rhythm tweaks. This tool can't guarantee any detector's verdict, and it won't turn someone else's ideas into your own work — use it to make your own drafts read more like you, not to misrepresent authorship.
