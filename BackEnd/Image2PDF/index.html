How lossless conversion works

01

Your image is read as raw bytes directly in the browser — nothing is uploaded to any server.

02

The raw image bytes are embedded into a minimal PDF wrapper as an XObject stream — no re-encoding, no compression, no quality loss.

03

The PDF is written and downloaded. The image inside is pixel-for-pixel identical to the original source file.
