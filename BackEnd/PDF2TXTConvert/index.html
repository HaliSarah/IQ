How It Works

01
Upload

Drop any number of PDFs at once. All files are handled locally in your browser — no uploads, no accounts.

02
Convert

Text is extracted from each PDF using pdf.js and saved as a plain UTF-8 .txt file.

03
Download

Grab each TXT individually, or download the whole batch as a zip file with one click. Done.

Note — This tool extracts the text layer from PDFs. Scanned documents (image-only PDFs with no embedded text) will produce empty .txt files. For scanned PDFs, run OCR first using a tool like Adobe Acrobat or Smallpdf before converting here.
